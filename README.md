# 📊 Информационно-аналитическая система анализа вакансий в сфере IT

## Описание проекта

Информационно-аналитическая система предназначена для исследования рынка вакансий в сфере информационных технологий в России. Особое внимание уделено факторам, влияющим на уровень заработной платы. Данные актуальны на момент последнего обновления: весна 2025 г.

Возможности системы:

- Визуальный анализ вакансий: тенденции, распределения, навыки, уровни зарплат
- Прогноз уровня заработной платы на основе введённых параметров 
- Интерактивный интерфейс для работы с результатами
- Возможность развёртывания в облачном сервисе
